# Demographic & Salary Data — Cleaning & Analysis

**Business problem.** Demographic and salary data arrives messy — inconsistent types, missing values, duplicates. Before any insight is possible, the dataset must be made reliable, then explored for salary patterns across demographic groups.

**Business questions.**
1. What cleaning is needed to make the data analysis-ready?
2. How does salary vary across demographic segments?
3. Which groups stand out, high or low, and why?

**Approach.** Inspected structure and types, handled missing values and duplicates, normalised formats, then aggregated and compared salary across demographic dimensions.

**Findings & next steps.** The notebook documents each cleaning decision and the resulting salary comparisons, with a takeaway at each step.

Notebook: [`notebook.ipynb`](./notebook.ipynb) — renders on GitHub, or open via the Colab link inside.

Tools: pandas.
