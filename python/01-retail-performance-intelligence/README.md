# Retail Performance Intelligence

**Business problem.** A retailer has behavioural and product data but no consolidated read on how users move through the funnel and which products perform. Stakeholders need one report, not scattered numbers.

**Business questions.**
1. How do users behave across the traffic funnel?
2. Which products and segments drive the most value?
3. Where are the drop-offs and opportunities?

**Findings & next steps.** Each finding in the report is paired with a recommended action for the owning team.

Report: [`retail_performance.html`](./retail_performance.html) — open in a browser to view the rendered analysis.

Note: this project is an HTML export of the notebook. If the original `.ipynb` is available, adding it lets GitHub render the code and charts inline.
